# Тригор Сантех — каталог

Приложение-каталог по PDF-прайсу TRIGOR: вкладки по видам товара, фото, цены, фильтры, поиск и корзина с суммой.
Работает как обычный сайт (без сервера): открыть `index.html` или включить GitHub Pages.

## Что умеет
- Вкладки: Раковина, Ванна и душ, Душевые стойки, Кухня, Биде, Водонагреватели, Подводки, Трапы, Комплектующие
- Поиск по артикулу и словам («лейка», «биде», «3 в 1», «чёрный»)
- Фильтры: цвет, материал, тип набора (2/3/4 в 1), цена от–до и быстрые диапазоны, «есть Фото+»
- Сортировка: сначала дешевле / дороже, по артикулу, по названию, как в прайсе
- Корзина: количество, цена по позиции и общая сумма, бюджет, курс в ₸, копирование списка, CSV, печать
- Кнопка «Фото+» открывает ссылку из прайса

## Как обновить по новому PDF (раз в 2–3 месяца)
```bash
pip install pdfplumber pillow
python3 tools/extract_pdf.py НОВЫЙ_ПРАЙС.pdf /tmp/raw
python3 tools/build_catalog.py /tmp/raw . 12.01.2027   # дата прайса
```
Скрипты пересоздают `data.js` и папку `img/`. Корзина сохраняется в браузере; товаров, которых нет в новом прайсе, из неё убираются с уведомлением.
Если в новом PDF сдвинулись номера позиций в разделах «Водонагреватели / Подводки / Трапы / Комплектующие», поправьте диапазоны в `category()` в `tools/build_catalog.py`.
