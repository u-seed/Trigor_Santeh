# Тригор Сантех — каталог

Приложение-каталог по PDF-прайсу TRIGOR: вкладки по видам товара, фото, цены, фильтры, поиск и корзина с суммой.
Работает как обычный сайт (без сервера): открыть `index.html` или включить GitHub Pages.

## Что умеет
- Два прайса — вверху переключатель **Тригор / Дионис** (у каждого свои вкладки и фильтры), корзина общая
- Вкладки: Раковина, Ванна и душ, Душевые стойки, Кухня, Биде, Водонагреватели, Подводки, Трапы, Комплектующие
- Поиск по артикулу и словам («лейка», «биде», «3 в 1», «чёрный»)
- Фильтры: цвет, материал, тип набора (2/3/4 в 1), цена от–до и быстрые диапазоны, «есть Фото+»
- Сортировка: сначала дешевле / дороже, по артикулу, по названию, как в прайсе
- Цены в тенге (основная валюта), доллар в скобках. Курс по умолчанию 450 ₸/$, меняется нажатием на «курс» вверху экрана
- Корзина: количество, цена по позиции и общая сумма, бюджет в ₸, копирование списка, CSV, печать
- Кнопка «Фото+» открывает ссылку из прайса

## Общая корзина (два телефона)
В «Корзине» → «Создать общую корзину» → «Отправить ссылку» второму телефону. Корзина обновляется у обоих раз в ~5 секунд, менять можно с любого.
Данные лежат в бесплатном анонимном хранилище jsonblob.com под длинным кодом (знающий код может прочитать/изменить корзину; в ней только артикулы и количества). «Отключить» — выйти из общей корзины.

## Как обновить по новому PDF (раз в 2–3 месяца)
```bash
pip install pdfplumber pillow
python3 tools/extract_pdf.py НОВЫЙ_ПРАЙС.pdf /tmp/raw
python3 tools/build_catalog.py /tmp/raw . 12.01.2027   # дата прайса
```
Скрипты пересоздают `data.js` и папку `img/`. Корзина сохраняется в браузере; товаров, которых нет в новом прайсе, из неё убираются с уведомлением.
Если в новом PDF сдвинулись номера позиций в разделах «Водонагреватели / Подводки / Трапы / Комплектующие», поправьте диапазоны в `category()` в `tools/build_catalog.py`.

## Установка как приложение
Откройте сайт (GitHub Pages) в Chrome на телефоне → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»). В Safari на iPhone: «Поделиться» → «На экран “Домой”». Установка требует https-адреса, `file://` не подходит.
После нового прайса увеличьте номер `V` в `sw.js`, если нужно сбросить кэш фото.

## Прайс Dionis
```bash
python3 tools/extract_dionis.py DIONIS.pdf /tmp/rawd
python3 tools/build_dionis.py /tmp/rawd . 12.01.2027      # -> data-dionis.js и img-d/
```
В PDF Dionis нет колонки «Материал»: он берётся из описания («Материал Нержавейка», «Zn»), для первых 12 позиций — из шапки «Смесители из нержавейки», иначе «Не указан». Упаковка — «1к=24шт» (коробка).
